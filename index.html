A transaction risk scoring project that learns from tabular data and returns a risk probability through an API. It includes preprocessing, class imbalance handling, model evaluation, and a simple way to inspect which features influenced a prediction.

A recommendation system that suggests items using user interactions and content similarity. I focused on building a clear recommendation pipeline, handling new users, evaluating the ranking, and exposing results through a lightweight API.

04Anomaly Detection

A log anomaly detector that turns application logs into simple numerical features and flags unusual activity using Isolation Forest. It also groups nearby alerts so the output is easier to inspect instead of showing a long list of isolated warnings.

PythonPandasscikit-learnSQL
